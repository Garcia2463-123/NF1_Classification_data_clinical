# NF1_Classification_data_clinical
Clinical dataset for Neurofibromatosis Type 1 (NF1) classification. Contains 19 features documenting patient phenotypes (café-au-lait spots, freckling, Lisch nodules), demographics (parental age, age at diagnosis), skeletal signs, and oncological profiles (gliomas, neurofibromas) for advanced predictive machine learning.
This clinical dataset compiles diagnostic profiles tracking phenotypic, demographic, and oncological characteristics of individuals evaluated for Neurofibromatosis Type 1 (NF1). Comprising 19 distinct features, the data serves as a structured repository for mapping the heterogeneous manifestations of this autosomal dominant, multi-system disorder.
A key focus of the dataset is tracking maternal and paternal ages alongside the patient's age at first diagnosis. This enables the study of spontaneous de novo mutations versus inherited familial lineages, which frequently correlate with parental age groups. The matrix captures core diagnostic criteria, including binary evaluations for hallmark dermatological features like café-au-lait spots (CLS), axillary freckling, and inguinal freckling. Ophthalmic and internal structural signs are also logged, specifically iris hamartomas (Lisch nodules) and optic pathway gliomas.
Beyond baseline diagnosis, the dataset logs nervous system tumors by separating superficial dermal neurofibromas from extensive, deeply tracking plexiform neurofibromas and central nervous system astrocytomas. The multi-system complications of NF1 are recorded through skeletal indicators (bone dysplasia and scoliosis) and secondary clinical comorbidities, including hypertension, benign hamartomas, learning disabilities, and unclassified systemic signs grouped under other symptoms.
Encoded cleanly using binary indicators (0 for absence, 1 for presence) alongside continuous age metrics, this dataset provides a standardized matrix optimized for advanced statistical modeling and machine learning applications. Researchers can leverage these records to construct early-stage predictive algorithms, evaluate risk stratification models for severe tumors based on visible skin phenotypes, and analyze the progression timelines of multi-system complications across different patient age groups.
